# r45 무선 장애 진단 준비와 FDB 메시지 정리

r44 위에 세 가지를 더했습니다. 무선/NPU 펌웨어와 커널 모듈은 r43·r44와 같고, 커널 이미지는 DSA 한 줄 때문에 바뀝니다
(ABI `6.18.44-w1700k-mlo-r32` 유지). MLO 간헐 멈춤이나 10월 5일 전 대역 연결 끊김의 원인을 고친 버전이 아닙니다.

- **FDB 메시지 정리**: 포크의 mac80211 패치가 단말이 떠날 때마다 FDB 삭제 알림을 보내고, DSA가 스위치에 없는 호스트 항목을
  지우려다 `failed to delete … from fdb: -2`를 남겼습니다. 단말 하나당 몇 초마다 두 줄씩 쌓여 128 KB 로그가 약 10분 만에 밀려났습니다.
  없는 항목 삭제를 성공으로 처리합니다(`9999-z7`). 브리지 흐름 정리 알림은 그대로입니다.
- **로그 보존**: 기본값이 비어 있거나 128 KB이면 1 MB로 올립니다. 사용자가 정한 값은 바꾸지 않습니다.
- **장애 감시**: 2.4 GHz와 MLD 양쪽에서 연결 직후 AP 쪽 강제 해제가 이어지는 패턴이나, 단말이 있던 두 AP가 5분 넘게 비는 패턴을
  감지하면 드라이버·큐·인터럽트·로그 상태를 `/tmp/w1700k-wifi-watchdog/`에 한 번 저장합니다(시간당 최대 1회, 2 MiB 이하).
  무선을 재시작하지 않습니다.

10월 5일 장애의 분석은 [OUTAGE_20261005.md](../mlo-r44/OUTAGE_20261005.md)에 있습니다. 실기기 확인 결과는 `BUILD_RESULT.json`에 있습니다.

## 빌드

[r44 절차](../mlo-r44/README.md)와 같고 config와 manifest만 r45 것을 씁니다(`r45.config`, `build-manifest.json`).
