# r72 — 온도센서 IRQ 등록 순서 보완

EN7581 온도센서의 IRQ 등록을 thermal zone 등록과 drvdata 설정 뒤로 옮겼습니다. 초기화 중 인터럽트가 아직 준비되지 않은 포인터를 사용하는 경로를 보완하고, 해제 시 IRQ가 thermal zone보다 먼저 정리되도록 합니다.

- Linux 6.18.59 기반이며 새 커널·모듈 식별자는 `6.18.59-w1700k-mlo-r72`입니다. 브리지 가속 패키지는 1.0-r9입니다.
- mt76 r43, r71의 NPU RX 수정과 원본 NPU 0.8·무선 펌웨어를 사용합니다. 기존 iPhone/MLO 송신 정지 문제는 계속 조사 대상입니다.
- 기존 드라이버를 거부하는 순서 검사와 브리지 가속 검사 22개를 통과했습니다. 전체 빌드 594.5초·종료 코드 0, 이미지·모듈·펌웨어·개인 설정 제외 검사를 통과했습니다.

기존 피드 순환 의존 경고 3건과 무시된 U-Boot 빈 패키지 정리 오류를 기록했습니다. GPIO PR26508은 W1700K 핀·부팅 검증이 더 필요해 이번 반영에서 보류했습니다. 실제 IRQ 강제 발생과 드라이버 unbind 시험은 수행하지 않았습니다.

공유기에 설치했고 SSH는 102.6초 후 복구됐습니다. 설정 5종, SSH 키, Tailscale 노드 식별자를 유지했으며 실제 모듈·펌웨어 해시는 이미지와 일치합니다. `OpenWrt_5G` 5+6GHz MLO와 별도 `OpenWrt_2G` 2.4GHz로 복귀했고 임시 Compat AP는 제거했습니다. 이전 LAN·Tailscale DNS 수정도 유지했습니다.

- Mac 무선으로 2.5Gbps 유선 서버에 연결해 각 방향 30초 측정: 다운로드 평균 1,971Mbps / 업로드 1,828Mbps, 0Mbps 구간 없음. 32MiB 무선 파일 왕복 해시 일치.
- MLO·2.4GHz 각각 DNS·인증서 검증 HTTPS·인터넷 ICMP 20/20 통과. 첫 자동 2.4GHz 연결은 확인되지 않아 해당 단계만 현재 인증정보로 재시도했고 통과했습니다. 최초 실패 기록도 보존했습니다.
- 허용된 설치 재부팅 외 유선 링크·공유기·서버 감시 3,578회, WAN·Proxmox 각 716회에서 실패 없음. 최대 관측 간격 5.08초이며 연속 무중단을 보증하는 기록은 아닙니다.
- 최종 CPU 온도 61.8°C, 주요 커널 오류 필터 0건. 두 MLO 링크·브리지 가속·유선 관리·Tailscale 정상.

최초 빌드 첨부물은 변경하지 않았습니다. 설치·시험 세부 결과는 추가한 `DEVICE_REPORT.md`, `DEVICE_TESTS.json`, `DEVICE_SHA256SUMS`에 기록했습니다. 이번에는 Mac만 측정했으며 iPhone 추가 속도 시험·장시간 절전·야간 안정성은 검증하지 않았습니다. 간헐적인 MLO 정지의 해결은 입증되지 않았습니다.
