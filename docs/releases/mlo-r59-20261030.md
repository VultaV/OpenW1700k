# r59 — 보안 갱신(커널 6.18.59, OpenSSL 3.5.9, rpcd·procd·ubus)

**실험용 prerelease입니다. 2026-10-30 실제 장치에 설치해 확인했습니다.** r58 위에 CVE 검토에서 나온 보안 갱신을
넣었습니다. mt76, hostapd, 무선·NPU 펌웨어는 r58과 같습니다. MLO 간헐 멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- 커널 6.18.55 → 6.18.59: stable의 네트워크 수정(IPv4 체크섬 검증, 여러 use-after-free, AF_PACKET 오버플로,
  flowtable 참조 누수와 VLAN untag underflow 등). 브리지 오프로드 패치를 새 커널에 맞췄습니다.
- OpenSSL 3.5.9: CVE 13건(High 1건은 DTLS 전용으로 이 장치는 쓰지 않음).
- rpcd 2026-10-28(비 root ubus 호출자에게도 세션 ACL 적용, 세션 ID를 파일 이름에 쓰지 않음)과 이에 필요한
  ubus 2026-10-28.
- procd 2026-10-18: ujail 격리 강화.
- 6.18.57 이후 커널에 맞춘 빌드 수정(mac80211 backports, NFS 보안 RPC·Intel ice 모듈 패키징). PF_RING 커널 모듈은
  새 커널에서 빌드되지 않아 패키지에서 뺐습니다(이미지에는 원래 없음).

## 검증

- r58에서 설정 유지로 설치, "Signature check OK". 커널 경고 없음, MLO 두 링크(5·6 GHz 160 MHz), 주요 서비스 정상.
- 브리지 오프로드 켜짐, fw4 flowtable 구성은 r58과 같음. LuCI 로그인과 rpcd 권한 확인 정상.
- Mac 무선(4흐름 30초): 하향 1,983·1,990·1,988 Mbps, 상향 1,830·1,805 Mbps.
