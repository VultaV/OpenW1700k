# r74 — W1700K Tailscale 업데이트

- 펌웨어에 포함된 Tailscale을 `1.102.2-r1`에서 `1.104.7-r1`로 올리고 Go `1.27.4`로 빌드했습니다. [Tailscale v1.104.7](https://github.com/tailscale/tailscale/releases/tag/v1.104.7)
- 기존 OpenWrt 서비스의 자동 시작과 설정 유지 업그레이드 시 `/etc/tailscale/` 보존 규칙을 유지했습니다. Tailscale 업데이트는 펌웨어 또는 OpenWrt 패키지로 배포합니다.
- r73 커널, DTB, 무선 드라이버와 ABI `6.18.59-w1700k-mlo-r73`를 유지했습니다. 최종 이미지 패키지 목록에서 버전이 올라간 항목은 Tailscale입니다.

첫 이미지에서 이전 버전 표기가 남아 있는 것을 확인해 `base-files` 재빌드 후 다시 조립했습니다. 최종 이미지의 UBI2 호환성, FIT 해시, 커널 모듈 ABI와 Tailscale 바이너리 버전을 검증했습니다. 공유기 부팅과 Tailscale 재접속은 장비에서 확인하지 않았습니다.

다음 빌드부터 이미지에 들어갈 패키지의 최신 안정 버전과 호환성을 확인해 반영합니다. 호환성 때문에 보류한 버전은 릴리스에 이유를 기록합니다.
