# r54 — 무선 사용자 영역·mac80211 upstream 추적과 오프로드 재적용 수정

**실험용 prerelease입니다. 2026-10-17 실제 장치에 설치해 확인했습니다.** r53 위에서 hostapd, wifi-scripts,
netifd, ubus, ucode, mac80211, nftables를 OpenWrt upstream main(2026-10-16)으로 맞추고 커널 수정 두 개와
브리지 오프로드 수정을 더했습니다. mt76 드라이버, 커널(6.18.55), 무선·NPU 펌웨어는 r53과 같습니다. MLO 간헐
멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- hostapd의 AP MLD 수정 18개(SA Query 시간 초과 뒤 재연결, 링크 추가 실패·제거 처리, 링크별 disassociation 등)와
  ubus 메모리 오류 수정. 포크 패치 두 개는 같은 내용이 upstream에 들어가 뺐습니다.
- mac80211: MLO 링크 하나가 멈춰도 MLD 인터페이스 carrier 유지, 관리 프레임의 링크 선택 등.
- 무선 설정 스크립트: MLD 하위 설정을 바꿀 때 전체 단말을 끊지 않음, 6 GHz/EHT 보안 기본값 정리.
- 커널: 출력 경로를 찾지 못한 흐름이 ifindex 0으로 오프로드되어 패킷이 반복해 버려지던 문제, QE 비트가 없는
  SPI-NAND(W25N04LV 등)에서 QE 비트를 건드리던 문제.
- 브리지 오프로드: wifi reload 뒤 오프로드가 꺼진 채 남던 문제 수정.

## 검증

- r53에서 설정 유지로 설치, "Signature check OK". 커널 경고 없음, NPU 정상, MLO 두 링크(5·6 GHz 160 MHz), 송신 출력
  23/18/23 dBm.
- Mac 재연결 3회 모두 MLO 두 링크. Mac 무선(4흐름 30초): 하향 1,729·2,003·1,972 Mbps, 상향 1,796·1,816 Mbps.
- 2.4 GHz 설정을 바꿔도 MLO 단말 연결이 유지되고, MLO SSID 설정을 바꾸면 단말이 두 링크로 다시 붙으며 오프로드가
  유지됩니다.
