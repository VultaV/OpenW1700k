# r48 — 커널 6.18.55

**실험용 prerelease입니다. 2026-10-08 실제 장치에 설치해 확인했습니다.** r46의 사용자 영역은 그대로 두고
커널만 6.18.44에서 6.18.55로 올렸습니다. 커널 ABI가 `6.18.55-w1700k-mlo-r32`로 바뀌어 모든 커널 모듈을 다시
빌드했습니다. 무선·NPU 펌웨어는 r46과 같습니다. MLO 간헐 멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- Linux 6.18.45–6.18.55 stable 수정(airoha pinctrl IRQ 수정 포함). upstream OpenWrt와 같은 방식으로 stable에
  들어간 패치를 지우고 나머지 패치를 갱신했습니다.
- 포크의 브리지 오프로드 패치(675-02·03)와 airoha 안정화 패치(992-20)를 새 커널에 맞췄습니다. NPU 워치독
  작업 수명 수정(9999-z3)은 6.18.55에 들어 있어 뺐습니다.
- mt76에 링크별 절전 전환 진단 카운터를 더했습니다(`hw-queues`의 `ps_transitions`).

## 검증

- 새 커널 소스로 브리지 TTL·conntrack·FDB 시험과 브리지 오프로드 시험이 통과했습니다.
- r46에서 설정 유지로 설치, `sysupgrade -T` "Signature check OK", 약 80초 만에 부팅. NPU 예산 가드 적용,
  세 라디오와 MLO 두 링크(5·6 GHz 160 MHz), 브리지 오프로드 동작, 커널 경고 없음.
- Mac 무선(6 GHz 160 MHz, 4흐름 30초): 하향 1,939·1,999 Mbps, 상향 1,604·1,622 Mbps. macOS AWDL이 활발하면
  몇 초씩 멈추는 현상은 그대로입니다([조사 기록](../mlo-r46/THROUGHPUT_20261007.md)).

## 알려진 제약

- 이 드라이버의 MLO 구성에서는 5·6 GHz 채널 스캔을 할 수 없습니다.
- r46 이전 이미지로 되돌리면 커널 모듈도 함께 바뀝니다. 다른 커널용 kmod를 섞어 설치하지 마세요.
