# r53 — upstream airoha_eth 백포트와 W25N04LV 지원

**실험용 prerelease입니다. 2026-10-17 실제 장치에 설치해 확인했습니다.** r52 위에서 OpenWrt upstream의 airoha
이더넷 드라이버 갱신(2026-10-16)을 가져오고 겹치는 포크 패치를 정리했습니다. mt76 드라이버, 커널(6.18.55),
무선·NPU 펌웨어는 r52와 같습니다. MLO 간헐 멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- airoha 이더넷 수정: RX 링 크기 확대, PPE SRAM flush 오류 처리, QDMA trtcm 설정 재시도, 공유 TX 링의 BQL
  언더플로, 조각 패킷 DMA 매핑, 최대 수신 크기, MIB·ETS 통계, GDM3/GDM4 QoS를 필요할 때만 WAN으로 전환,
  LRO v7.
- 포크 패치 중 upstream이 같은 문제를 고친 2개(HW-GRO 상태 공유, PPE flush 오류 전파)를 뺐고, 나머지는 새
  드라이버에 맞췄습니다. LAN 쪽 기기들이 QDMA를 함께 쓰므로 공유기 자체가 끝점인 TCP의 LRO는 꺼집니다.
  공유기를 거쳐 가는 흐름은 오프로드라 영향이 없습니다.
- Winbond W25N04LV 플래시 지원(이 칩이 들어간 하드웨어 리비전용, 실기기 미확인).

## 검증

- r52에서 설정 유지로 설치, "Signature check OK", 약 95초 만에 부팅. 커널 경고 없음, NPU 정상, 유선(10G 내부·
  2.5G·1G)·인터넷 정상, MLO 두 링크(5·6 GHz 160 MHz), 송신 출력 23/18/23 dBm, 오프로드 흐름 204개.
- Mac 재연결 3회 모두 MLO 두 링크로 연결.
- Mac 무선(4흐름 30초): 하향 1,979·1,972·2,006 Mbps, 상향 1,839·1,838 Mbps. 접속 직후 첫 하향 회차는
  919 Mbps로 중간에 떨어졌고(이전 버전과 같은 양상), 이후 회차는 정상이었습니다.
