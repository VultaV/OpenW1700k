# r46 — 소프트웨어 탭 복구, DNS 동시 질의 손실 수정, 무선 장애 진단

**실험용 prerelease입니다. 2026-10-07 실제 장치에 설치해 확인했습니다.** 공개하지 않은 r45의 변경을 함께 담았습니다.
커널 ABI(`6.18.44-w1700k-mlo-r32`)와 커널 모듈·무선/NPU 펌웨어는 r44와 같습니다. MLO 간헐 멈춤과 10월 5일 전 대역
연결 끊김의 원인을 고친 버전은 아닙니다.

## 고친 것

- **소프트웨어 탭**: r44에서 원격 패키지 피드를 모두 빼 목록이 비었습니다. snapshot의 base·packages·luci·routing 피드를
  다시 넣고, 이 이미지의 커널과 맞지 않는 target·kmods 피드는 넣지 않습니다. 첫 부팅 때 이미지의 패키지 210개를 이미지
  버전으로 고정해 `apk upgrade`나 소프트웨어 탭이 패치한 LuCI·hostapd 등을 snapshot 빌드로 덮어쓰지 않게 합니다.
  새 패키지는 설치할 수 있지만, kmod가 필요하거나 고정된 패키지의 새 버전이 필요한 패키지는 설치되지 않습니다.
- **DNS 동시 질의 손실**: 작은 UDP 패킷 하나가 수신 버퍼를 약 16 KB 차지해 dnsmasq가 동시에 온 질의를 12개 정도만
  받았습니다. 기본 수신 버퍼를 1 MB로 올렸습니다. 동시 질의 20/40/80/120개의 응답이 12/12/12/12에서 20/40/67/85가 됐습니다.
- **FDB 오류 로그(r45)**: 단말이 떠날 때마다 `failed to delete … from fdb: -2`가 쌓여 로그가 약 10분 만에 밀려났습니다.
  스위치에 없는 항목 삭제를 성공으로 처리합니다.
- **로그 보존(r45)**: 시스템 로그 기본 크기를 128 KB에서 1 MB로 올립니다. 사용자가 정한 값은 바꾸지 않습니다.
- **무선 장애 감시(r45)**: 전 대역 강제 해제가 이어지거나 단말이 있던 AP가 5분 넘게 비면 드라이버·큐·로그 상태를
  `/tmp/w1700k-wifi-watchdog/`에 한 번 저장합니다(시간당 최대 1회). 무선을 재시작하지 않습니다.

## 검증

- r45에서 설정 유지로 설치, `sysupgrade -T` "Signature check OK". 패키지 고정 210개, `apk upgrade` 시뮬레이션 변경 0개,
  새 패키지 설치 시뮬레이션 성공. 세 라디오와 MLO 두 링크(5·6 GHz 160 MHz) 동작, FDB 오류 로그 0건.
- 호스트 시험 9종 통과. 상세는 [r46 기록](../mlo-r46/README.md)과 `BUILD_RESULT.json`에 있습니다.

## 알려진 제약

- 이 드라이버의 MLO 구성에서는 5·6 GHz 채널 스캔을 할 수 없습니다.
- 패키지 피드는 rolling snapshot이라 시간이 지날수록 설치할 수 없는 패키지가 늘어납니다.
- MLO 처리량이 몇 초씩 떨어졌다 회복하는 문제는 남아 있습니다.
