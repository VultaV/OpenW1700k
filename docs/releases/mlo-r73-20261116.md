# r73 — W1700K 무선 드라이버 안정화 패치

r72의 Linux 6.18.59를 바탕으로 무선 스택을 갱신했습니다. 커널·모듈 ABI는 `6.18.59-w1700k-mlo-r73`입니다.

- mt76 r44는 TXFREE 헤더와 완료 항목을 온전한 단위로 읽도록 검사합니다. 이미 처리한 항목의 완료 처리는 유지합니다. 5초 경과 토큰의 강제 회수는 DMA 소유권과 지연 완료 검증을 위해 보류했습니다. [커뮤니티 수정](https://github.com/OpenWRT-fanboy/OpenW1700k/commit/aa332819f707311fd99e945d1bb6e293211812c4)
- mac80211의 채널 예약, 단말·RX BA 정리, 조각 수신 길이 및 RTS 임계값 수정 6건을 반영했습니다. [OpenWrt 수정](https://github.com/openwrt/openwrt/commit/24c13d794c810e14b52bd6e9720a1f512b5e5f23)
- AP MLD에서 `mlo_emlsr`과 `mlo_emlmr`로 각 모드의 광고를 끌 수 있습니다. 값을 생략하면 드라이버가 지원하는 모드를 사용하며, 해당 모드가 없으면 EML 필드를 생략합니다. [hostapd](https://github.com/openwrt/openwrt/commit/cfae1f57f8cc73675db76d50c91da9509c8dfbd7) · [wifi-scripts](https://github.com/openwrt/openwrt/commit/8e3f6ad698203479e7f678c9b71b07f59e413d34)

TXFREE 길이 10개, EML 조합 5개, 브리지 가속 22개와 DFS·NPU 회귀 검사를 통과했습니다. 최초 이미지 조립은 r72 ABI가 남아 있던 GPIO 버튼 패키지에서 멈췄습니다. 해당 패키지를 새 ABI로 재빌드한 뒤 전체 빌드가 537.7초에 종료 코드 0으로 완료됐습니다. 기존 Kconfig 순환 의존 진단 3건과 무시된 U-Boot 빈 패키지 정리 오류는 빌드 기록에 남겼습니다.

FIT 페이로드와 UBI2 호환성, 커널 모듈 74개의 ABI, EML 설정 포함 여부를 확인했습니다. NPU 0.8·MT7996 파일의 해시는 r72 계열과 일치합니다. 공유기 설치·부팅과 iPhone MLO 재현 검사는 아직 진행하지 않았습니다.
