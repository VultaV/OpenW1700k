# r52 — upstream 0 dBm 송신 출력 수정과 mt7530 VLAN 백포트

**실험용 prerelease입니다. 2026-10-16 실제 장치에 설치했고 2026-10-17 시험했습니다.** r51 위에 OpenWrt upstream
커밋 두 개를 더했습니다. mt76 드라이버, 커널(6.18.55), 무선·NPU 펌웨어는 r51과 같습니다. MLO 간헐 멈춤의 해결
여부는 바뀌지 않았습니다.

## 바뀐 것

- 송신 출력을 0 dBm으로 설정하면 auto로 처리되던 문제 수정(upstream `5ee6f1fdbe`).
- 스위치 드라이버 mt7530의 VLAN 수정 두 개(Linux v7.1, upstream `3a985c7398`): VLAN-aware 브리지를 없앤 뒤
  VLAN-unaware 브리지가 연결을 잃는 문제, untagged PVID 트래픽이 브리지 VLAN 인터페이스에 닿지 않는 문제.

## 검증

- r51에서 설정 유지로 설치, "Signature check OK", 약 95초 만에 부팅. MLO 두 링크(5·6 GHz 160 MHz), 송신 출력
  23/18/23 dBm(r51과 같음), 유선·인터넷 정상, 커널 경고 없음.
- 0 dBm 설정이 실제로 0.00 dBm으로 적용되고, 설정을 지우면 auto(23 dBm)로 돌아옵니다.
- Mac 재연결 3회 모두 MLO 두 링크로 연결.
- Mac 무선(4흐름 30초): 하향 2,013·2,024·2,018 Mbps, 상향 1,833·1,832 Mbps.
