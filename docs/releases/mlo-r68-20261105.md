# r68 — 펌웨어 MLD 식별자와 전송 링크 분리 (실험 버전)

**실기기 전송 회귀로 시험을 중단하고 r65 복구를 완료했습니다. 2.4+5GHz 다운로드1.3Mbps·7초 정지, 2.4+6GHz184.9Mbps·6초 정지를 관찰했습니다. 이 버전은 사용을 권장하지 않습니다. `DEVICE_REPORT.md`와 `DEVICE_TESTS.json`에 실패·복구를 기록했습니다.**

r67의2.4+6GHz 시험에서 큰 속도 저하와 정지를 관찰했습니다. 이번 버전은 최신mt76의 upstream1e1ca91 전체5파일을 반영합니다. 전송할 링크가 바뀌어도 펌웨어의 최초 연결 WCID를 유지하고, PEER_MLD 명령으로 연결 정보를 STA_REC보다 먼저 전달합니다. 명령 실패 시 연결 설정을 중단하며, 연결 이후 추가되는 파트너 링크는 기존 MLD_SETUP 경로로 갱신합니다.

- 기존 데이터 링크 선택0042, 제거 전용 처리0044, 관리 프레임 링크 선택0045와 DFS 수정을 유지합니다.
- mt76 패키지r41. 커널·외부 모듈 ABI는 `6.18.59-w1700k-mlo-r67`을 유지합니다. 변경은MT7996 내부 상태·명령 직렬화이며, 공통 커널/NPU/QDMA 구조와 API는 바뀌지 않습니다. 일치하는mt76 모듈 세트로 배포합니다.
- NPU 풀과원래QDMA, vendor NPU0.8·기존Wi-Fi 펌웨어·hostapd/wpad r9를 유지합니다. 별도 확인 중인NPU0.8 zero-budget 가드는 이 버전에 포함하지 않습니다.
- 실제 준비 소스의 새 검사99개와 기존MLO 검사20개 통과(ASan/UBSan). 고정식별자 처리를 되돌린 비교에서는 예상 오류2개가 재현됐습니다. MCU 전송·펌웨어 실행은 호스트 검사에서 재현하지 않습니다.

이 변경이r67의14Mbps 저하 원인인지 아직 확인되지 않았습니다. 빌드·이미지 검사 후 실험용 prerelease로 배포하며, 설치·부팅·속도 시험은 별도 기록합니다. 실제 약전계 전환·전체 OS잠자기·야간 장기 안정성은 미검증입니다.

최종 이미지 빌드402.6초(선행mt76 컴파일374.8초). SHA256: `4912b42d4fc32000cfe6392bf129e4f61c1c193445a31d08ed6b172c87e4615a`. UBI2/FIT·r67 공통ABI·NPU 풀·모듈·비공개 상태 미포함 검사 통과. NPU0.8과Wi-Fi 펌웨어6개가r67과 동일함을 실제 이미지에서 확인했습니다.
