# r75: 누락된 MLO·hostapd 수정 및 Linux 6.18.64

설치된 r74를 기준으로 11월 25일 비교에서 확인한 적용 가능한 미반영 수정을 백포트했습니다. 기존 NPU 보호 코드와 무선 구성을 유지합니다. 간헐적인 iPhone/MLO 장애가 해결됐다는 결론은 아직 없습니다.

## 변경 사항과 이유

- **커널 6.18.59 → 6.18.64**: 안정 커널 수정을 반영하고 기존 패치 문맥을 정리했습니다. 안정 커널에 포함된 세 패치는 중복을 제거했습니다. 새 ABI는 `6.18.64-w1700k-mlo-r75`이며 모듈을 모두 재빌드했습니다.
- **커널 호환성 보정**: 기존 sockaddr_unsized 보정이 6.18.61 이후에는 구조체 정의를 누락하는 빌드 오류를 수정했습니다. 공식 6.18.57~64 헤더 비교와 11개 버전 조건 검사를 기록했습니다.
- **mt76 r45**: 재연결 시 WCID의 연결·비활성 상태를 복원하고, 채널 문맥이 없는 station의 키 설정을 허용합니다. 보조 링크 선택과 MLD 설정 명령의 링크 쌍을 맞추며 기존 데이터 링크 선택기는 유지합니다. 하드웨어 재정렬 경로의 QoS TID 기록, CCMP-256/GCMP 수신 PN, IGTK/BIGTK 설치 시 GTK PN 상태 유지, 소프트웨어 BA 재정렬 시 PN 검사 순서를 수정합니다.
- **mac80211 r15**: AP VLAN 재시작 콜백, MLD 수신 station 조회, MLO station의 airtime 집계를 보완합니다.
- **hostapd r11**: 해제된 BSS의 null 참조, 설정 초기화 누락, CAC 중 불필요한 재시작, 삭제한 MLD 링크 ID의 미반환을 수정합니다.
- **wifi-scripts r6**: cell-density 허용 범위 오류를 수정합니다.
- **기존 서비스 유지**: Tailscale 1.104.7-r1과 현재 설치된 W1700K용 UniFi 0.3.0 포트 및 hostapd-utils/veth 의존성을 이미지에 포함합니다. Tailscale·UniFi 상태 디렉터리 보존 경로를 검증합니다. UniFi 신규 설정은 기본 비활성화이며 기존 공유기에서는 `enabled=1, apply=0` 설정을 유지합니다.

## 적용 범위와 보류

이번 요청의 ‘미반영된 부분만’ 범위에 따라 관련 수정과 커널을 갱신하고 일반 피드·다른 패키지는 검증된 r74 커밋으로 고정했습니다. Tailscale 1.104.7과 UniFi 0.3.0은 확인 시 최신 안정 버전입니다. NPU 0.8 두 파일과 MT7996 펌웨어 여섯 파일은 최신 공개본과 같아 유지했습니다.

기존 NPU RX 보호 코드와 겹치는 재조립 변경, DMA 소유권이 검증되지 않은 timeout 토큰 회수, 드라이버 opt-in이 필요한 deferred airtime(508), 새 PEER_MLD 명령 전제가 필요한 fw_mld_idx 계열은 보류했습니다. 보조 링크 수정은 현재 STA_REC_MLD 인코딩에 맞춰 적용했습니다.

## 검증

호스트 회귀 검사의 상세 결과와 한계는 `HOST_CHECKS.json`, 컴파일은 `BUILD_RESULT.json`, 이미지·모듈·펌웨어 검증은 `IMAGE_CHECKS.json`에 기록합니다. PN 63개 검사, 링크 쌍/TLV 36개 조합과 기본·제거 경로, 이전 코드의 실패 대조, 브리지 22개 검사와 r75 ABI의 네 실행 경로, NPU RX·게시 순서, DFS·EML·TXFREE 검사를 포함합니다. 오래된 lifecycle 테스트는 r74 API와 맞지 않아 컴파일되지 않았으며 통과로 계산하지 않았습니다. 현재 링크 쌍과 TLV 함수는 별도 추출해 검사했습니다.

전체 재빌드가 517.88초/종료 코드 0으로 완료됐고 FIT·UBI2·이미지 해시·모듈 75개 ABI·펌웨어·개인 상태 미포함·서비스 보존 경로 검증을 통과했습니다. 런타임 패키지는 213개입니다. 설치·부팅은 아직 수행하지 않았으며 결과는 별도 기기 보고서로 추가합니다. 호스트 검사는 무선/NPU 펌웨어 실행이나 동시 커널 동작을 증명하지 않습니다. iPhone 앱·절전 복귀·약한 신호·야간 안정성은 이번 원격 작업에서 검증되지 않았습니다.

## 설치

`gemtek,w1700k-ubi` **UBI2 전용 실험 버전**입니다. 설정을 보존하는 정상 sysupgrade와 장치 자체 이미지 검사를 사용합니다. r74 모듈과 혼용하지 마세요. 이미지에는 개인 설정·암호·SSH 키·Tailscale 상태·UniFi 등록 정보가 포함되지 않습니다. 원격 설치 동안 네트워크가 잠시 끊길 수 있습니다.
