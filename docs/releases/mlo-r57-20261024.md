# r57 — flow offload 상태의 로밍 수정

**실험용 prerelease입니다. 2026-10-25 실제 장치에 설치해 확인했습니다.** r56 위에서 OpenWrt upstream의 flow
offload 로밍 수정 두 건을 가져왔습니다. mt76, hostapd, ucode, 무선·NPU 펌웨어, 커널 버전(6.18.55)은 r56과 같습니다.
MLO 간헐 멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- 오프로드된 흐름의 단말이 다른 DSA 포트나 다른 MAC으로 옮겨 가면 흐름이 끊기던 문제 수정(upstream `279704475c`):
  포워드 경로 계산이 ctx를 받도록 바뀌고, ieee80211 포워드 경로가 복구되며, 출력 장치가 바뀐 흐름을 정리합니다.
- mac80211의 ieee80211 포워드 경로 복구(upstream `d014acb494`).
- 포크의 브리지 오프로드 패치를 새 코드에 맞췄습니다.

## 검증

- r56에서 설정 유지로 설치, "Signature check OK". 커널 경고 없음, MLO 두 링크(5·6 GHz 160 MHz), 라우팅·브리지
  flowtable 생성, 부팅 직후 오프로드 흐름 204개.
- Mac 재연결 3회 모두 MLO 두 링크. Mac 무선(4흐름 30초): 하향 1,962·1,971·1,960 Mbps, 상향 1,802·1,802 Mbps.
- 인터넷(WAN 1 GbE): 하향 887 Mbps, 상향 783 Mbps.
- 단일 AP 환경이라 AP 간 로밍과 포트 이동 자체는 재현하지 못했습니다.
