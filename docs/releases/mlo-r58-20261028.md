# r58 — upstream 보안·flowtable·사용자 영역 묶음

**실험용 prerelease입니다. 2026-10-28 실제 장치에 설치해 확인했습니다.** r57 위에서 OpenWrt upstream main(2026-10-28)의
커밋 16개를 가져오고 브리지 오프로드 패치를 다시 맞췄습니다. mt76, hostapd, mac80211, 무선·NPU 펌웨어, 커널 버전
(6.18.55)은 r57과 같습니다. MLO 간헐 멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- 보안: dnsmasq CVE 수정 7건(DNS 이름 버퍼 오버플로, 힙 범위 밖 쓰기 등), musl regcomp 정수 오버플로.
- flowtable: 포워드 경로를 찾지 못한 흐름이 목적지 MAC 0으로 나가 브리지 전체에 퍼지던 문제 수정(기존 `699` 대체),
  로밍 흐름 정리 v9, VLAN ID 수정, DSA 호스트 FDB 포트별 관리.
- 무선·사용자 영역: 6 GHz 링크가 있는 MLD의 sae_pwe 처리, ucode·firewall4·netifd 갱신. 새 firewall4는 소프트웨어
  오프로드 flowtable에 브리지 대신 실제 포트를 넣고, 새 netifd는 유선 RPS를 인터럽트 CPU 밖으로 옮깁니다.
- 포크: 브리지 오프로드 패치를 새 flowtable 코드에 맞췄고, upstream이 근본 원인을 고친 `9999-z7`을 뺐습니다.
  변경 묶음은 코드 리뷰를 거쳤습니다.

## 검증

- r57에서 설정 유지로 설치, "Signature check OK". 커널 경고 없음, MLO 두 링크(5·6 GHz 160 MHz), DNS·인터넷 정상.
- fw4와 브리지 오프로드 flowtable이 함께 동작하고, 부팅 직후 오프로드 흐름 241개.
- Mac 재연결 3회 모두 MLO 두 링크. Mac 무선(4흐름 30초): 하향 1,936·1,956·1,958 Mbps, 상향 1,791·1,818 Mbps.
- 인터넷(WAN 1 GbE): 하향 898 Mbps, 상향 773 Mbps.
