# r55 — ucode 2026-10-18과 맞물린 사용자 영역 갱신

**실험용 prerelease입니다. 2026-10-19 실제 장치에 설치해 확인했고, 2.5일 동안 재부팅·커널 경고 없이 동작했습니다.**
r54 위에서 ucode를 OpenWrt upstream main(2026-10-18)으로 올리고, 맞물린 패키지를 함께 갱신했습니다. 커널(6.18.55),
mt76, hostapd, mac80211, 무선·NPU 펌웨어는 r54와 같습니다. MLO 간헐 멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- ucode 2026-10-18: use-after-free 여러 건과 ubus 응답 누수 수정. hostapd·netifd·무선 설정 스크립트가 ucode로 동작합니다.
- uhttpd 2026-08-24: URL 접두어 핸들러의 Basic Auth realm 강제(GHSA-5cgm-8h9x-v28c) 포함.
- 새 ucode에 맞춰 uhttpd·rpcd 빌드 수정, udebug 갱신, ucode를 쓰는 패키지 전체 재빌드.
- 원격 snapshot 피드의 ucode 관련 패키지는 라이브러리 이름이 달라 맞지 않을 수 있습니다.

## 검증

- r54에서 설정 유지로 설치, "Signature check OK". 커널 경고 없음, NPU 정상, LuCI·ubus RPC 정상.
- Mac 재연결 3회 모두 MLO 두 링크. Mac 무선(4흐름 30초): 하향 1,980·1,991·1,989 Mbps, 상향 1,831·1,812 Mbps.
- 2.4 GHz 설정을 바꿔도 MLO 연결 유지, MLO SSID 설정을 바꾸면 두 링크로 다시 접속하고 오프로드 유지.
- 설치 후 2.5일: 재부팅·커널 경고·끊김 스냅샷 없음, 오프로드 정상.
