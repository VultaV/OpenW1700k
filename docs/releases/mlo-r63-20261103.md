# r63 — NPU v0.8 시험 펌웨어와 MLO 수정 4건

r62 위에 NPU 시험 바이너리와 확인된 MLO 수정 4건을 통합한 **실험 버전**입니다. 기존 MLO 멈춤·2.4GHz 포함 시 하향 정체·장시간 후 연결 실패의 해결이 확인된 버전은 아닙니다.

## 변경 사항

- EN7581+MT7996 NPU 파일 쌍을 제조사 저장소의 **v0.8 test version**으로 교체했습니다. 패키지 버전은 `0.8-r1`입니다.
- 비 MLO 802.3 프레임에서 단말의 실제 링크를 사용합니다 (`451f47376280`).
- 링크를 제거하기만 할 때 MLD_SETUP을 다시 보내지 않습니다. 남은 링크의 전송이 멈출 수 있는 경로에 대한 수정입니다 (`d8d24d7cbf5d`).
- MLO 관리 프레임을 지정된 링크로 전송합니다 (`46b67e5b7c49`).
- MLD의 CCMP 재전송 방지 PN 상태를 링크 간 공유하고, 키 설치마다 한 번만 초기화합니다 (`59b149d24e27`). 관련 mt7996·mt7925 호출부를 함께 반영했습니다.
- 기존 r62 best-link 선택·PS·NPU DMA/descriptor·mailbox·브리지 TTL 보호는 유지합니다. 이전에 미커밋 상태였던 r60–r62 소스와 정리된 측정 기록도 포함합니다.

**주의:** 기존 NPU TX-budget 가드는 이전 파일 쌍의 정확한 해시에만 적용됩니다. 새 v0.8 파일은 해당하지 않아 변경 없이 로드되며 `not applicable`로 기록됩니다. 이전 바이너리의 명령어 오프셋을 새 파일에 적용하지 않았습니다. 새 펌웨어에 같은 budget 보호가 있는지는 확인되지 않았습니다.

## 검증

- 실제 패치된 소스의 MLO 검사 20건 통과(ASan/UBSan). 동일한 기존 소스에서는 5건 실패를 재현했습니다.
- best-link 선택 10건, PS/AQL 29건, MLO PS 29+99건 및 활성 링크 검사 통과.
- NPU 로더·probe의 기존 가드/오류 경계 24건, v0.8 DT/default 경로 2건 통과. 새 파일의 SHA256과 바이트 불변성을 검사했습니다.
- 오래된 링크 전환 검사기는 현재 소스에 없는 함수를 요구해 실행되지 않았습니다. 통과로 처리하지 않았습니다.
- 최종 `gmake -j12 V=s` 성공(427초). 실제 이미지의 W1700K UBI2 구조·전체 payload CRC32/SHA1·SHA256, NPU 2개 파일 원본 일치, mt76 r39 모듈 3개·ABI, 내장 manifest, 비공개 상태 파일 미포함을 확인했습니다. 상세 결과는 `BUILD_RESULT.json`과 `IMAGE_CHECKS.json`에 기록했습니다.
- 커널·DTB payload는 보존한 r62 이미지와 바이트 단위로 일치합니다. NPU와 MLO 수정을 기존 커널 위에 통합한 이미지입니다.

## 설치 및 제약

- 커널/모듈 ABI: `6.18.59-w1700k-mlo-r32`, mt76 pin `639e1287`, mt76 package release **39**.
- **이번 r63의 공유기 설치·부팅·실측·장시간 안정성 시험은 하지 않았습니다.** 호스트 검사는 NPU 명령 실행이나 무선 타이밍·동시성·DMA 하드웨어를 검증하지 않습니다.
- UBI2 W1700K용입니다. 다른 커널 ABI의 모듈을 섞지 마세요. 기존 설정·Tailscale 비공개 상태는 이미지에 포함하지 않습니다.
- 이전 설치된 r62 manifest의 0042 패치 해시 차이는 과거 재현성 제약으로 남깁니다. 이번 r63은 별도의 정확한 소스 커밋과 파일 해시를 기록합니다.
