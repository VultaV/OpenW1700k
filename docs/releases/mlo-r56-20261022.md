# r56 — hostapd upstream 2026-10-21

**실험용 prerelease입니다. 2026-10-22 실제 장치에 설치해 확인했습니다.** r55 위에서 hostapd를 OpenWrt upstream
main(2026-10-21)으로, uhttpd를 2026-10-19로 맞췄습니다. 커널(6.18.55), mt76, mac80211, ucode, 무선·NPU 펌웨어는
r55와 같습니다. MLO 간헐 멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- hostapd의 AP MLD 수정: 첫 링크 재시작 시 BSS 유지, 공유 인증자 처리, 링크별 EAP 모드, 중단된 스캔 재시도, 링크 ID
  할당, 시작하지 않은 링크를 요청하는 연결 거부 등. 기존 패치는 hostap 제출본으로 정리됐습니다.
- uhttpd 2026-10-19: 새 ucode 대응과 ubus list 요청 인자 검증. r55에서 넣은 포크 uhttpd 패치는 뺐습니다.

## 검증

- r55에서 설정 유지로 설치, "Signature check OK". 커널 경고 없음, NPU 정상, MLO 두 링크(5·6 GHz 160 MHz), 송신 출력
  23/18/23 dBm, 오프로드·LuCI 정상.
- Mac 재부팅 직후 무선(4흐름 20초): 하향 1,849·1,998 Mbps, 상향 1,801 Mbps.
- 같은 날 같은 조건으로 r55와 재연결 8회씩 비교해 r56이 더 나쁘다는 근거는 없었습니다. r56에서는 맥이 8회 모두
  6 GHz 링크로 붙었습니다. 이 날은 맥 쪽 절전 동작 때문에 두 펌웨어 모두 속도가 낮은 구간이 있었습니다
  ([r56 기록](../mlo-r56/README.md)).
