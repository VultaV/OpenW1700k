# r64 — 대역별 DFS 처리와 송신 복구

r63 위에 야간 Wi-Fi 장애 조사에서 확인한 DFS 경로를 수정한 **실험 버전**입니다.

- 공유 hw에 NULL context로 레이더 이벤트를 보내 모든 대역에 확산하던 경로를 수정했습니다. 감지한 radio의 현재 context에만 RCU 보호 범위에서 전달합니다. 배경 레이더와 사라진 context를 구분합니다.
- AP 재시작/CAC fallback 후 운영 채널 설정이 성공했을 때, DFS 상태가 disabled/active이면 중단된 MAC 송신을 재개합니다. CAC·unknown·offchannel·설정 오류 중에는 재개하지 않습니다. DFS 초기화/MCU 오류를 반환합니다.
- 짧은 RDD 보고에서 band selector를 읽지 않습니다.
- r63의 NPU v0.8 시험 파일 쌍과 기존 MLO 수정은 유지합니다. 옛 NPU budget 가드는 새 파일에 해당하지 않습니다.

## 검증

- 실제 C DFS 검사: 기존 공통 21개 중 8개 실패 → 수정 후 22개 통과(추가 1개는 짧은 보고 검사), ASan/UBSan.
- 기존 MLO 20개, best-link 10개, MLO PS 29+99개 통과.
- 최종 빌드 성공. 실제 UBI2 이미지의 구조·payload 해시·NPU 파일·mt76 r40 모듈/ABI·내장 manifest·비공개 상태 미포함을 확인했습니다. 커널/DTB payload는 r63과 같습니다.
- 커널 ABI `6.18.59-w1700k-mlo-r32`, mt76 pin `639e1287`, 패키지 release **40**.

현재 본문은 빌드 공개 시점의 기록입니다. **장비 설치·부팅·DFS·MLO 검증은 진행 예정이며 아직 해결 확정이 아닙니다.** 이후 결과는 DEVICE_TESTS 기록과 갱신된 본문으로 추가합니다. 호스트 검사는 실제 펌웨어·NPU·동시성을 재현하지 않습니다. 이미지는 UBI2 W1700K용이며 비공개 설정·SSH 키·Tailscale 상태를 포함하지 않습니다.
