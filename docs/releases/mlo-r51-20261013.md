# r51 — mt76 드라이버 2026-10-08

**실험용 prerelease입니다. 2026-10-13 실제 장치에 설치해 확인했습니다.** r50 위에서 mt76 무선 드라이버만
`01367e60`(2026-09-01)에서 `639e1287`(2026-10-08)로 올렸습니다. 커널(6.18.55)과 무선·NPU 펌웨어는 r50과
같습니다. MLO 간헐 멈춤의 해결 여부는 바뀌지 않았습니다.

## 바뀐 것

- upstream mt76 커밋 90개. MLO 단말 링크 처리(돌아오는 링크 복원, 대표·보조 링크 선택, 링크별 BA 설정, 링크
  제거 시 정리), 여러 라디오 동시 스캔, NPU 장치의 송신 BA 타이머 갱신, PLE 레지스터 오프셋, 펌웨어 이벤트
  길이 검증 등이 들어 있습니다.
- 포크 패치 중 upstream이 같은 버그를 고친 3개(링크 선택자 복원, 링크 할당 실패 시 WCID 반환, NPU BA 타이머)를
  뺐고, 나머지는 새 드라이버에 맞췄습니다. 송신 출력 제한은 r50에서 확인한 방식(SKU·백오프 표)을 유지합니다.

## 검증

- mt76 호스트 시험 6종 통과. r50 대비 바뀐 커널 모듈은 `mt76.ko`, `mt76-connac-lib.ko`, `mt7996e.ko` 3개입니다.
- r50에서 설정 유지로 설치, "Signature check OK", 약 80초 만에 부팅. NPU 예산 가드, 세 라디오와 MLO 두 링크
  (5·6 GHz 160 MHz), 송신 출력 23/18/23 dBm(r50과 같음), 브리지 오프로드, 커널 경고 없음.
- Mac 재연결 3회 모두 MLO 두 링크로 연결.
- Mac 무선(6 GHz 160 MHz, 4흐름 30초): 하향 1,954·1,868·1,980 Mbps, 상향 1,809·1,791 Mbps.
