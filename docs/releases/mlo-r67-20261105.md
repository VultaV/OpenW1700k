# r67 — NPU 메모리 풀 단독 검증 (실험 버전)

**실기기 검증에서 2.4+6GHz 다운로드14Mbps·업로드 중1초 정지를 관찰했습니다. 나머지 세 조합은 약1.9Gbps였으나 전체 안정화는 실패했으며, 원인 분리 시험 중입니다. 설치·부팅·설정 보존·NPU 풀 검사는 통과했습니다. `DEVICE_MATRIX_INITIAL.json`에 실패를 보존했습니다.**

r66은 NPU 메모리 풀과 QDMA 정리를 함께 적용했지만, 설치 직후 내부 서버·Proxmox 통신 검사에 실패해 r65로 복원했습니다. r67은 원인을 분리하기 위해 QDMA를 r65와 동일하게 되돌리고 NPU coherent 메모리 풀만 유지합니다. r66에서 관찰한 실패의 원인이 어느 변경인지는 아직 확정하지 않았습니다.

- NPU가 접근할 수 있는 DRAM 범위 안에 WLAN용16MiB 풀을 예약합니다. 기존 coherent 메일박스와 일반 streaming DMA 처리는 유지합니다.
- r65의 라디오별 레이더 처리·DFS160 대피 수정, NPU0.8, mt76r40, hostapd/wpad r9를 유지합니다.
- 커널/모듈 ABI: `6.18.59-w1700k-mlo-r67`. 브리지 가속 패키지r7의 ABI 검증도 함께 갱신했습니다. 다른 버전의 모듈을 섞지 마세요.
- 호스트 검사: 실제 풀 연결/정리7개, 기존 메일박스145개, 브리지 가속22개 통과. QDMA의 준비된 C·헤더는 저장해 둔 r65 원본과 해시가 같습니다.

이 문서는 빌드·이미지 검사 후 배포되는 실험용 prerelease의 사전 기록입니다. r67 설치·부팅·성능은 아직 미검증이며, 설치 후 유선 관리 경로로 두 내부 서버를 먼저 확인하고 실패하면 즉시 r65로 복원합니다. 이후 실제 결과를 별도 기록합니다.

r65의 초기 TCP 정지와 일부 흐름 저하가 해결됐다는 증거는 아직 없습니다. 실제 약전계 전환·전체 OS잠자기·야간 장기 안정성은 별도 검증이 필요합니다.
