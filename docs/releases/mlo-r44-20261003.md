# r44 — 관리 화면·업데이트 경로의 보안과 정확성 수정

**실험용 prerelease 후보입니다. 아직 장치에 설치·부팅하지 않았습니다.** r43의 커널·모듈·무선/NPU
펌웨어는 바이트 단위로 같고, 이미지의 사용자 영역만 바뀌었습니다. 원래 Air의 간헐적인 MLO 멈춤과는
관계가 없으며 해결 여부도 바뀌지 않았습니다.

## 고친 것

- **root 권한 실행 경로**: netspeedtest의 `arch` 입력이 다운로드 URL을 고르는 sed를 바꿔 임의 바이너리를
  root로 설치·실행할 수 있었습니다. flowsense는 조작된 ping 결과를 root awk 코드로 실행했습니다.
  LuCI의 `/dev/mem` 쓰기 권한을 없애고, NPU PLL 오버클럭은 순정 1200 MHz까지로 막았습니다
  (20자리 값으로 범위 검사를 우회하던 정수 넘침 포함).
- **권한 범위(F01)**: wifi7 앱의 ACL이 기본 네트워크 그룹에 섞여, 읽기 권한만으로 `wifi down`·`iw`·`hostapd_cli`를
  실행할 수 있었습니다. 앱 전용 그룹으로 나누고 실행 권한은 쓰기 쪽에만 둡니다.
- **관리자 화면 스크립트 삽입(XSS)**: SSID·암호화·모드·ifname·프리셋·핑 대상·GitHub 릴리스 태그가
  HTML로 들어가던 곳 11곳을 텍스트로 바꿨습니다.
- **무선 설정이 바뀌던 문제**: wifi7 Networks 탭이 표준 무선 페이지에서 정한 `psk2+ccmp` 등을 목록에 없다는
  이유로 "개방"으로 보여 주고, 저장하면 **암호 없는 AP**가 됐습니다. MLD 탭은 `wpa3-192` 등을 `sae`로 낮췄고,
  사용자 지정 네트워크는 `lan`으로 바뀌었습니다. 저장값을 그대로 유지합니다. 또한 실패한 저장 뒤 재시작(F05),
  다른 프로필 편집(F07), 존재하지 않는 인터페이스 조회(F08), 비활성 MLO 프로필 저장 거부(F06)를 고쳤습니다.
- **표준 무선 페이지**: 다중 라디오 MLO 섹션을 단일 라디오처럼 켜고 끄지 않도록 막고 MLO 페이지로 안내합니다.
- **팬**: `40.5` 같은 값 하나로 팬이 수동 모드에 고정되고 재부팅해도 풀리지 않던 문제를 고쳤습니다.
- **GitHub 업데이트**: 이미지의 jq에 정규식이 없어 r29–r43의 업데이트 화면은 장치에서 항상 403/502로
  끝났습니다. 정규식 없이 검사하고, 저장소를 `VultaV/OpenW1700k`로, 체크섬을 `SHA256SUMS`로 맞추고,
  "설정 유지" 선택을 실제 검사·설치에 반영합니다.
- **sysupgrade 검사**: 이 보드에서 FIT 해시와 UBI2 배치를 검사합니다. 맞지 않는 이미지는 `-F`로도 거부합니다.
- **패키지 피드**: 커널이 다른 OpenWrt snapshot의 kmod를 설치하지 않도록 원격 피드를 넣지 않습니다.
- **빌드**: ca-certificates를 다시 빌드할 때 인증서가 두 번 들어가던 문제(r43 이미지의 241개 블록)를 고쳤고,
  r43이 실제로 쓰던 채널 분석 패치(5 GHz 탭 "No data" 수정)를 저장소에 보존했습니다.

## 검증

- 공개 소스로 r43을 처음부터 다시 빌드해 설치·검증된 r43과 비교했습니다. 모듈 74/74, 펌웨어 11/11, wpad, DTB가
  같습니다. r44 이미지도 같은 비교에서 모듈 74/74, 펌웨어 11/11, wpad가 같고, 새 패키지는 `w1700k-fit-check`와
  `libfdt`뿐입니다. r43에만 있던 파일은 중복 인증서 240개뿐입니다.
- 모든 수정은 수정 전 실패·수정 후 통과하는 호스트 시험이 있고, 작성자와 다른 검증자가 다시 확인했습니다.
  화면 수정 일부는 이미지의 `luci.js`로 headless Chrome에서 확인했습니다.
- FIT 검사: 이 Mac의 W1700K sysupgrade 이미지 60개 모두 `fit_check_sign`을, 58개 모두 `w1700k-fit-check`를
  통과했습니다. r44와 r43은 통과하고 chainload 이미지는 거부됩니다.
- 장치·브라우저 실사용 확인은 하지 않았습니다.

## 설치 전 주의

이 이미지 이후의 sysupgrade는 FIT 검사를 통과해야 합니다. 처음 설치할 때 유선 관리 경로와 복구 수단을
준비하고, 설치 직후 `sysupgrade -T`로 이 이미지와 r43 이미지가 통과하는지 확인하세요. r44에서 r43으로
