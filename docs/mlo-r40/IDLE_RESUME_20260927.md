# r40 Mac 유휴 후 MLO 전송 확인 — 2026-09-27

Wi-Fi 설정 화면 대신 General 화면을 유지한 Mac에서 **120.439초 동안 의도적인 Wi-Fi 부하를 멈춘 뒤, 120초 다운로드**를 실행했다. r39에서 이미 정상으로 확인한 동일 조건을 r40에서 검증한 결과다. 펌웨어·무선 설정·PPE 규칙을 바꾸지 않았다.

| 조건 | 평균 Mbps | 최저 1초 Mbps | 최고 1초 Mbps | 0Mbps 표본 |
|---|---:|---:|---:|---:|
| 이전 r39, 120초 유휴 후 120초 전송 | 1951.84 | 1816.59 | 2018.50 | 0 |
| 현재 r40, 같은 길이 유휴·전송 | 1936.72 | 1861.00 | 2004.38 | 0 |

r40은 500Mbps 미만 표본도 0개이고 첫 1초는 1886Mbps였다. 한 번씩의 비교에서 약 15Mbps 평균 차이를 RED의 개선·악화로 해석하지 않는다. **이번 조건에서 유휴 후 전송 정체는 재현되지 않았다.**

## 경로와 관측 확인

- 시험 전후 같은 대상의 5+6GHz 두 링크 `0x6`, 실제 TCP 데이터 연결 4개의 PPE binding을 확인했다.
- 유선 관리 HTTP **261회 모두 정상**. 서버 LAN2는 2.5Gbps, Mac 관리 LAN4는 1Gbps를 유지했다. 27개 CPU/링크 표본과 26개 구간이 수집됐고 boot/config 비교도 일치했다.
- 실제 idle 동안 en0 수신 91,682bytes·송신 6,449bytes가 있었다. Mac은 깨어 있었으며 background 트래픽까지 완전히 끈 시험이 아니다.
- idle 종료 후 약 5.157초 동안 유선 observer를 준비한 뒤 iperf를 실행했다. idle 뒤 Wi-Fi HTTP 사전 확인을 다시 보내지 않았으므로 첫 의도적 Wi-Fi 부하는 TCP 연결이었다.
- 대상의 보장된 idle 내부 구간에 PS 기록 192개, host TXQ gate=1 기록 48개가 있었다. 보장된 전송 내부 구간에는 PS 4개와 gate=1 기록 1개가 있었지만 고속 수신은 유지됐다. 이는 host 상태 기록이며 실제 무선 절전 지속 시간이나 NPU 내부 완료의 측정이 아니다.
- 방출된 kernel 기록 1,150개의 순번은 연속이었다. 전체 단말 P 기록 1,148개에서 첫/끝 사이 누락은 0개였고 F 기록은 0개였다. 기록 경계나 rate-limit에 의한 모든 누락까지 배제하는 수치는 아니다.
- Mac Wi-Fi 설정 확장의 검색 요청은 0개였다. 일반 live-scan API 호출은 idle 중 1회 관측됐고, 전송 시작 약 17.96초 전에 시작해 0.387초 뒤 끝났다. API 수행 시간은 RF off-channel dwell 시간이 아니다. reader drop 문구·stderr는 0개였다.
- 서버 TCP 재전송 합계는 4,378이다. 평균 속도가 정상이라는 결과를 손실·재전송이 전혀 없다는 뜻으로 해석하지 않는다.

시계 표본 10개가 같은 offset 구간과 양립했고 그 폭은 19.086ms였다. 실제 데이터 시작을 감싼 별도 시간 폭은 0.209초다. 시작 불확실성 구간의 PS 이벤트는 `ps.traffic` 내부 집계에 포함하지 않으므로, 그 수치만으로 첫 기상 이벤트의 부재를 주장하지 않는다.

## 복원과 판단 범위

PS 진단·console 설정 자동 복원, `ps_trace=N`·awake 시험 OFF·UCI 미적용 변경 없음, 같은 부팅을 확인했다. Mac은 원래 iPhone 핫스팟과 General 화면으로 복원했고 핫스팟 HTTPS200·유선 HTTP200도 확인했다. 추가 설치·재부팅은 하지 않았다.

Mac이 TCP 연결을 먼저 개시하므로, 이 결과는 Mac 전체 sleep/wake나 AP가 먼저 잠든 단말에 보내는 downlink 시험이 아니다. 첫 PPE snapshot은 3초 이후, 자동 dip dump는 10초 이후여서 첫 기상 지연의 모든 내부 경로를 포착하는 도구도 아니다. **원래 Air의 간헐 멈춤 해결, NPU RRO 실패 경로가 실행되지 않았음, 모든 일상 사용 조건의 정상 여부는 입증하지 않는다.**
