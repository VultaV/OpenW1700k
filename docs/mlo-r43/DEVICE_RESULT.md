# r43 설치 및 Mac 기본 전송 확인

2026-09-27. **r43 설치 후 30개 검사와 Mac 다운로드·업로드 시험을 통과했다.** 이는 설치와 제한된 전송 확인 결과이며, 원래 Air의 간헐적 절전 복귀 멈춤이나 성능 저하를 해결했다는 판정은 아니다.

## 설치 확인

- 설치 검사 **30 PASS / 0 FAIL / 0 WARN / 0 SKIP**, 통과율 100%. 새 부팅, 실행 중인 r43·커널 ABI, 이미지와 일치하는 모듈 74개, 실행 중인 wpad를 확인했다.
- 설정 파일 34개의 해시가 설치 전후 같았으며, 별도로 보존한 일반 파일 1,443개의 경로·해시도 일치했다. 기존 Tailscale 연결·식별 상태, LAN2 2.5Gbps, Mac 유선 관리와 AP 활성 상태를 확인했다.
- NPU guard 적용 로그가 정확히 한 번 기록됐고, 그 뒤 NPU 버전 응답을 확인했다. 원본 program/data 펌웨어 파일은 그대로다. 적용 로그는 알려진 조합의 **부팅 전 DRAM 사본 변경과 readback 검사**를 통과했다는 근거이며, 모든 NPU 실행 경로의 정상 동작을 증명하지는 않는다.
- 수집한 부팅 로그에서 해당 초기화 오류를 관측하지 않았고 현재 devcoredump는 없었다. 과거 로그 손실이나 사라진 dump까지 배제하는 검사는 아니다.
- 허용된 설치 중 유선 HTTP의 마지막 정상 표본과 첫 복구 표본 사이가 **171.110초**였다. 실패 표본의 처음부터 마지막까지는 166.061초이며, 물리 링크 단절 시간을 측정한 값은 아니다.

## Mac 전송 결과

TCP 4개 흐름을 사용했고 별도 목표 속도 제한은 설정하지 않았다. 다운로드는 60초, 업로드는 20초로 시험 길이가 다르다.

| 시험 | 수신 측 평균 | Mac 1초 구간 최저 | Mac 1초 구간 최고 | 0바이트 구간 | 유선 확인 |
|---|---:|---:|---:|---:|---:|
| 다운로드 60초 | 1,129.152Mbps | 406.136Mbps | 1,401.521Mbps | 0/60 | 78회 정상 |
| 업로드 20초 | 1,298.188Mbps | 1,254.688Mbps | 1,379.078Mbps | 0/20 | 34회 정상 |

다운로드의 평균·구간 수치는 Mac 수신 기준이다. 업로드 평균은 Linux 서버 수신 기준이고, 구간 최저·최고는 Mac 송신 기준이므로 관측 지점이 다르다. 송신 측 TCP 재전송 보고는 각각 8,401회·3,252회이며, 이를 실제 무선 손실 패킷 수로 해석하지 않는다.

두 회차 모두 실제 데이터 연결 4개를 iperf 연결과 대조했다. 네 연결의 conntrack과 `HW_OFFLOAD` 플래그, 흐름당 PPE bound 엔트리 2개를 확인했다. 이는 기록된 시점의 등록 증거이며 모든 패킷이 가속 경로를 통과했다는 연속 검증은 아니다. Mac의 MLO 링크 비트맵은 전후 모두 `0x6`이었지만 두 링크의 동시 데이터 전송량을 판정하지는 않았다.

시험 중 설정·부팅이 유지됐고 유선 관리 확인은 총 **112회 모두 정상**이었다. 1초 구간에 전송량 0이 없었다는 사실만으로 그보다 짧은 멈춤이 없었다고 단정할 수 없다.

## 해석 범위

추가 단말의 5/6GHz 링크가 전후 기록에 함께 나타났다. 다른 단말의 트래픽·무선 사용 시간을 통제하지 않았으므로, 과거 약 1.9Gbps 결과보다 낮은 이번 수치를 r43의 개선이나 회귀로 직접 판정할 수 없다. 또한 이 두 회차에는 native 스캔·PS 전이·서버 패킷을 같은 시계로 비교하는 원인 검증이 없다.

후속 시험 뒤 최종 상태 검사도 21 PASS / 0 FAIL / 0 SKIP이었다. 설치 직후와 부팅·설정·모듈·진단 상태가 같았고, 유선·AP·NPU 응답이 유지됐다.

원래 Air 멈춤은 미해결 상태로 유지한다. 이번 문서는 완료된 설치·Mac 시험 시점의 증거만 다루며, 후속 2.4GHz IPv6/Matter 감사나 이후 장치 상태를 대신하지 않는다. 수치와 입력 파일 해시는 [DEVICE_RESULT.json](DEVICE_RESULT.json)에 보존했다. 원시 단말 식별자, 설정 백업, 패킷 및 개인 경로는 포함하지 않았다.
