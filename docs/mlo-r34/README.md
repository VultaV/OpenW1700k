# r34: 링크 수명 관리·NPU watchdog·업데이트 UI

r33 전체 검토에서 재현한 코드 결함을 최소 범위로 수정한다. 빌드·이미지 검증 결과는 `BUILD_RESULT.json`, 입력 해시는 `build-manifest.json`, 빌드 절차는 `BUILD.md`에 기록한다. **장비 설치·부팅·무선 성능은 미검증이며 Air 절전 복귀 멈춤의 해결을 주장하지 않는다.**

9개 빌드 명령은 성공했지만 경고 없는 빌드는 아니다. `BUILD_WARNINGS.json`에 경고 1,076줄(반복 포함), 정규화 메시지 309종과 관련 설정·이미지 포함 여부를 기록한다. 회귀 검사 통과와 경고의 무해성은 구분한다.

| 항목 | r34 변경 | 검증 범위 |
| --- | --- | --- |
| F02 | 링크 추가·제거·실패 복구 뒤 실제 활성 링크로 primary/secondary 선택자를 정리. primary 교체 시 공유 TXQ의 WCID 갱신 | 실제 함수 추출 C, ASan/UBSan. 유효 링크 0x7을 유지하면서 활성 링크가 0x3→0x6으로 바뀌는 사례 포함 |

| N01 | 공식 Linux `4bdee8060d1e4581624e68fbd369b1afb14df4bc` 백포트. work 초기화 후 IRQ 등록, IRQ 해제 후 work 취소 | 실제 probe/IRQ와 devm helper 추출. 즉시 IRQ 유무와 probe 실패 경계 검사 |

커널 release/ABI는 `6.18.44-w1700k-mlo-r32`를 유지한다. 커널 payload와 두 모듈을 제외한 모든 모듈은 r33과 바이트가 같아야 한다. 변경 가능한 모듈은 `airoha_npu.ko`, `mt7996e.ko`이며 공개 인터페이스·공유 구조체 변경은 없다. 새 NPU/MT7996 펌웨어 바이너리를 넣은 버전은 아니다.

## 남은 항목과 새 upstream 정보

[전체 검토](../mlo-r33/FULL_REVIEW_20260926.md)의 F01(위임 읽기 계정의 Wi-Fi 실행 권한), F05(UCI 실패 후 재시작), F06(비활성 프로필 저장), F07(프로필 선택), F08(사용자 지정 ifname 상태 조회)은 이번 수정에 포함하지 않는다. F02/F03/F09/F10은 소스 수정 완료이며 실기기 검증 완료를 뜻하지 않는다. F04의 기존 전달 경로와 제한은 유지한다.

최신 일반 UBI2 `ubi2_2026.09.26_r36602-54e453b074` 및 커뮤니티 자료는 위 전체 검토에 소스·실제 이미지 비교와 함께 기록돼 있다. 새 995/996은 순수 L2 TTL·교차 ingress 보호이며 기존 KEEP_TTL·PPE 소유권·FDB 수정을 통째로 대체하지 않는다. RX31/GRO/ring 및 공개 mt76 PR은 별도 병합 후보로 유지한다. r34는 최신 upstream 전체 교체가 아니다.

NPU 재구현 프로젝트의 kite errata는 현재 사용 바이너리의 파일명·해시·명령어 위치와 직접 대응하지 않는다. 이를 우리 펌웨어에서 확인한 결함이나 Air 멈춤의 원인으로 기재하지 않는다. 현재 r32 장비에서 약 2Gbps까지 회복한 CPU/가속 병목과 남아 있는 간헐 멈춤은 구분한다.
