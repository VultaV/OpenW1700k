# r41 연결 초기 타이머 관측

상태: **EARLY_ASSOCIATION_OBSERVED**. 데이터 시작의 연결 나이는 **8.123–8.967초**다. 상한 20초 미만 조건은 True이며, 늦게 시작했다면 연결 초기 타이머와 TCP 시작을 구분하는 시험으로 인정하지 않는다.

40초 평균 599.97Mbps, 최저 46.21Mbps, 500Mbps 미만 14개·0Mbps 0개다. 새 데이터 연결 4개의 conntrack 존재와 OFFLOAD/HW_OFFLOAD·PPE 부재, 같은 association/0x6, 유선 HTTP 54회 정상과 공유기 상태 유지가 확인됐다. 서버 재전송은 3078회이며 RF 손실 횟수와 같지 않다.

native 완결 scan 호출 36쌍과 BEST CONNECTED 타이머 기록 3개를 JSON에 남겼다. API 구간은 RF 체류 시간이 아니다. 방출된 kernel 기록 807개는 연속이지만, 전 단말 P/F 기록의 내부 누락은 각각 184/0개다. 보장된 전송 창 안의 대상 P 기록 384개, gate=1 96개이며, 마지막 wake와 회복의 정확한 지연을 이 수치만으로 확정하지 않는다.

대상과 일치하는 BA 진단 메시지는 21개를 관측했다. 없는 메시지는 미관측이며, aggregate 상태나 MCU 성공을 실제 BA 전달·동작의 증거로 바꾸지 않는다. 첫 저하의 연결 나이와 TCP 상대 시각을 native/PS 기록과 함께 비교해야 하며, 한 번의 정상 전송이나 무재현은 수리 완료가 아니다. 원래 Air 절전 복귀 문제의 인과관계도 별도다.
